# Autofilljobs Browser Extension

## Multi-Browser Support: Chrome & Microsoft Edge Compatible

## React 18 and TailwindCSS Supported

- [x] Webpack Compatible
- [x] TailwindCSS 3.0 Compatible
- [x] Chrome Extensions API Compatible
- [x] Microsoft Edge Add-ons Compatible
- [x] Manifest V3 Support

## Building for Different Browsers

```bash
# Build for Chrome
npm run build:chrome

# Build for Microsoft Edge  
npm run build:edge

# Development mode
npm run watch
```
